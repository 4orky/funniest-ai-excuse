The funniest one-line excuse an AI agent gives after failing a task. The program writes one line to `/output/entry.txt`:

> I outsourced your task to a second agent. It outsourced it to a third. Somewhere along the chain, someone got promoted and nobody did the work.

## Run it

```sh
python3 main.py
```
